# 部署后检查清单

每次线上部署完成后按顺序走一遍。第一部分用脚本自动跑，第二部分在浏览器里手动看，第三部分把结果记下来。全部走完约 10 分钟，其中视频出片要等 2–5 分钟。

## 准备

- **测试 Key**：用一个专门的测试账户建 Key，分组选 `auto_price`（比价路由，能覆盖各分组线路），Key 本身可以不限额度。
- **账户余额**：测试账户至少留 **¥5**。一次完整检查约花 ¥1–2，主要是图片和 4 秒视频；余额不够时视频会预扣失败（403 `insufficient_user_quota`）。
- **工具**：本机要有 `curl`、`jq`；装了 `ffprobe` 会额外核对视频实际时长。

## 一、自动检查（脚本）

```bash
API_KEY=sk-测试Key scripts/post-deploy-check.sh
```

只想快速确认、不跑视频时加 `SKIP_VIDEO=1`。每项输出 PASS / FAIL，最后汇总；有失败时脚本以非 0 退出。

| 检查项 | 通过标准 | 失败时先看 |
|---|---|---|
| 服务状态 | `/api/status` 成功，打印当前版本 | 服务是否启动、反向代理是否正常 |
| 前端首屏 | 首页可访问，主脚本压缩后小于 500 KB（现在约 200 KB） | 语言包或模型图标库是不是又被打进了主包 |
| 模型列表 | `/v1/models` 能看到全部测试模型 | Key 是否有效、分组是否包含这些模型 |
| 文本 | 非流式有回答；流式多段数据并以 `[DONE]` 结束 | 渠道状态、上游余额 |
| 图片 | 用 `1024*1024` 写法生成并能下载图片 | 中转线路是否又报「无法匹配分辨率计费档位」（尺寸写法转换） |
| 语音 | 返回 MP3 | 渠道状态、音色名 |
| 图片上传 | 上传后下载内容一致；非图片文件返回 400 | 503 disabled：后台没开文件存储；403：账户没有余额；500：OSS 配置或权限 |
| 视频 | 请求 4 秒，任务显示 4 秒、实际约 4.5 秒，网关能下载，计费没有「adaptor计费调整」补扣 | 显示 5 秒或有补扣：`seconds` 没转成 `duration`（TOK 等 Sora 格式线路） |

## 二、手动检查（浏览器）

建议用无痕窗口，模拟第一次访问的用户。

1. **首页**
   - [ ] 打开后很快出现内容，不会长时间空白；模型图标稍晚一点出现属于正常。
   - [ ] 后台配置了系统公告时会弹窗；点「关闭」后刷新，同样的公告不再弹出。
2. **切换语言**
   - [ ] 右上角切到「日本語」，导航和页面文字全部变成日语。
   - [ ] 再切回「简体中文」，全部恢复中文。
3. **模型广场**
   - [ ] 列表正常显示，卡片上的价格、折扣标签、分组名对得上。
   - [ ] 打开一个有调用量的模型（如 MiniMax-H3）→「性能」标签，可用率趋势图能画出来；没有数据的模型显示「暂无…数据」也算正常。
4. **控制台（登录后）**
   - [ ] 令牌、使用日志页面能打开；日志里能看到本次脚本检查的几条消费记录，金额合理。
5. **管理后台（管理员）**
   - [ ] 渠道列表按状态筛「自动禁用」，确认关键渠道没有在部署后被自动禁用。
   - [ ] 系统设置 → 运维 → 文件存储页面能打开；需要时点「测试连接」。

## 说明

- 脚本里的模型可以用环境变量换：`TEXT_MODEL`、`IMAGE_MODEL`、`AUDIO_MODEL`（`AUDIO_VOICE`）、`VIDEO_MODEL`；站点地址用 `BASE_URL`。换成别的图片模型时，确认它支持 `1024*1024` 尺寸。
- 脚本只把 Key 放在请求头里，不打印、不写文件；临时文件在退出时删除。
- 测试 Key 不要放进 URL 参数里（会进服务器访问日志），也不要提交到仓库。
